# Документация по проекту

## 1. Назначение и цели проекта
Проект представляет собой набор модулей для анализа туристических маршрутов и оценки их опасности по координатам и времени их прохождения. В состав входят:
- **Агенты** для очистки "грязного" датасета и обучения моделей машинного обучения.
- **Дэшборд** с аналитикой и визуализацией маршрутов.
- **API-сервис** для онлайн-предсказаний опасностей по координате.
- **Веб-приложение** для прогнозирования опасности на маршрутах по выбранной дате.

## 2. Архитектура проекта
**Схема взаимодействия:**
1. Пользователь выбирает маршрут/дату (Dash) или отправляет координаты (FastAPI).
2. Агент данных получает исходные признаки из БД и формирует запросы к внешним API.
3. Агент признаков добавляет вычисленные признаки (температура, высота, окружение и т.д).
4. Агент модели выполняет прогноз.
5. Агент визуализации отображает результат (карта/графики) или отдаёт JSON-ответ.

## 4. Запуск и настройка

### 4.1. Зависимости
Минимальный набор библиотек:
- `pandas`, `plotly`, `dash`, `fastapi`, `uvicorn`, `joblib`, `openmeteo-requests`, `requests`, `sqlite3`, `statsmodels`, `tqdm`, `geopy`.

Рекомендуется использовать виртуальное окружение:
```bash
source .venv/bin/activate
pip install -r requirements.txt
```
### 4.2 Запуск Веб-приложения (на фоне так же запускает API-сервис)
```bash
python "Проект №6 (последний срез)/Application (Module_D)/main.py"
```

### 4.3. Запуск Дэшборда (Module_B/main.py)
```bash
python "Проект №6 (последний срез)/Dash (Module_B)/main.py"
```

## 5. Важные замечания по переносимости
- В исходном коде используются **абсолютные пути Windows** (например, `C:\Users\...`). Для запуска в другой среде необходимо заменить пути на относительные или на конфигурируемые значения.
- API-запросы к Open-Meteo и Overpass требуют доступ в интернет.

## 6. Технологии
- **Python** (основной язык программирования).
- **Dash/Plotly** (веб-визуализация и интерактивные дэшборды).
- **FastAPI + Uvicorn** (API-сервис для предсказаний).
- **SQLite** (локальная база данных).
- **Pandas** (обработка данных).
- **Joblib** (хранение и загрузка моделей).
- **ARIMA** (прогноз температуры).
- **Open-Meteo API / Overpass API** (внешние источники признаков).
